# Amazon Clone

A responsive front-end clone of the Amazon homepage built using HTML and CSS. This project recreates Amazon's user interface, including the navigation bar, hero section, product categories, and footer while focusing on responsive design and clean layouts.

## Features

- Responsive navigation bar
- Hero banner section
- Product category cards
- Search bar UI
- Footer with multiple sections
- Clean and responsive layout

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## What I Learned

- HTML page structure
- CSS Flexbox
- CSS Grid
- Responsive web design
- Styling with CSS
- Working with icons using Font Awesome
- Building real-world UI layouts

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
